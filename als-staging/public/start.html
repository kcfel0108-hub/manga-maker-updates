SETLIST

曲順、尺、MCなどを整理。過去のライブ資料をベースに次の公演を作れます。

STAGE PLOT

メンバー、アンプ、マイク、DIなどを配置し、視覚的なステージ資料を作成。

INPUT / OUTPUT

PAに必要なI/O情報を整理。ステージ情報と合わせて確認できます。

PA / LIGHTING

PA・照明への要望を一か所に集約。現場へ渡す情報の抜け漏れを減らします。

EQUIPMENT

持ち込み機材、バックラインなどを整理。公演ごとの変更にも対応。

EXPORT & BACKUP

資料出力とプロジェクトバックアップに対応。重要な資料は.alsprojでも保存できます。
